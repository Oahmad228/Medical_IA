# IA en Sante - Site vitrine

Site vitrine (expose en ligne) sur l'intelligence artificielle en sante, base sur le projet Medical AI. Cette page presente les enjeux, applications, risques, methodologie de veille, et un focus prototype.

## Demarrage rapide

```bash
npm install
npm run dev
```

Le site est disponible sur http://localhost:5180.

## Structure

- index.html : contenu principal (sections, navigation)
- style.css : theme, layout, animations, responsive
- script.js : scroll fluide et animations au defilement

## Notes

- Site statique, aucun build requis.
- Les textes sont en ASCII pour compatibilite maximale.
