Medical AI – Dual Agent System

Système d'assistance médicale basé sur l'intelligence artificielle avec deux agents spécialisés : Agent Patient et Agent Médecin. Développé avec Node.js, React et Prisma pour une architecture robuste et sécurisée.

I

Définition du sujet

Concept du système (2 IA + 1 passerelle)

IA 1 — Assistant Patient

Objectif : Aider le patient à décrire, trier, et suivre son problème.

  • Collecte guidée des symptômes
  • Questionnaire dynamique
  • Conseils de base non dangereux
  • Triage intelligent (urgence, médecin sous 24-48h, surveillance)
  • Orientation vers spécialité adaptée
  • Suivi longitudinal des améliorations

⚠️ Important : N'effectue pas de diagnostic. Oriente et accompagne uniquement.

IA 2 — Assistant Médecin

Objectif : Aider le médecin à analyser et produire des documents structurés.

  • Résumé des données médicales
  • Aide à l'interprétation clinique
  • Proposition de diagnostics différentiels
  • Génération de compte-rendu patient
  • Plan de suivi et alertes
  • Validation médicale requise

⚠️ Important : N'assiste que le médecin, ne le remplace pas.

Passerelle — Dossier Patient

Cœur du projet : Gestion sécurisée et éthique des données patient.

  • Stockage de l'historique complet
  • Gestion granulaire du consentement
  • Journalisation audit-compliant
  • Anonymisation pour la recherche
  • Chiffrement bout-en-bout
II

Méthodologie & Sources

Approche de veille et flux d'implémentation

Approche de développement
  • Architecture modulaire (Backend/Frontend séparés)
  • Triage déterministe pour la sécurité médicale
  • Séparation stricte des rôles Patient/Médecin
  • Validation médicale obligatoire
  • Tests et sécurité en priorité
Technologies & Outils
  • Backend : Node.js, Express, Prisma, SQLite
  • Frontend : React 18, Vite, Bootstrap
  • IA : OpenRouter/Groq API, règles déterministes
  • Sécurité : JWT, rate limiting, validation Zod
  • Outils : Git, VS Code, Postman

Flux complet - Scénario réaliste

1. Patient → IA Patient

Description des symptômes + photo optionnelle

2. Questionnaire dynamique

Questions sur durée, intensité, antécédents, traitement essayé

3. Conseils + Triage

Conseils de base + niveau d'urgence (urgence, 24-48h, surveillance)

4. Orientation

Proposition de spécialité + médecins proches (selon localisation)

5. Consultation

Médecin accède au pré-dossier structuré avec timeline

6. Analyses & Résultats

Upload des résultats (PDF/texte) + interprétation IA Médecin

7. Explication Patient

Version vulgarisée validée par le médecin + suivi proposé

Frontend
  • Framework : React 18
  • Build : Vite
  • Routing : React Router
  • State : React Hooks
  • UI : Bootstrap/Material-UI
IA & Sécurité
  • Triage : Règles déterministes
  • LLM : OpenRouter/Groq
  • Sécurité : Rate limiting
  • CORS : Configuré
  • Validation : Input sanitization

Limites et compliance

Principes fondamentaux
  • L'IA ne remplace pas un médecin : elle assiste et complément
  • IA Patient : pas de diagnostic, pas d'ordonnance, conseils exclusivement de base
  • IA Médecin : propose (hypothèses), le médecin décide et valide
  • Protection des données : consentement granulaire + audit + RGPD compliance
